# АгроЯсно — визуальное демо для GitHub Pages

Это статический автономный прототип для согласования дизайна, анимаций и структуры разделов. Создан на основе демонстрационного интерфейса исходного проекта; backend, авторизация и MySQL **не используются**.

Запуск: `index.html`. При публикации через GitHub Pages используется workflow `.github/workflows/pages.yml` с загрузкой только содержимого `site/`.

## Важно
- Числа, сроки, ведомства, «открытые отборы» и профили — **демонстрационные** и не являются актуальной информацией о господдержке.
- Изменения через демонстрационную админку сохраняются только в localStorage конкретного браузера.
- На главной есть заметный дисклеймер; нет реального входа или отправки заявок.
- Для production потребуется развёртывание серверной части и проверка исходных данных.
